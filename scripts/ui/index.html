      実行前に黒い画面で下を実行してください (電源につないだ状態で、蓋は開けたまま)。

powercfg /change monitor-timeout-ac 0
        

      検査が終わったら元に戻してください。

      代理店コードによる表示差分を調べる
      

        

          これは検査ではありません。パターンごとに代表 1 社ずつ LP を開き、
          「代理店コードによって何が変わるのか」を洗い出して
          reports/discovery/agency-section-diff.md に出します。
          サイトの仕様が変わったときに、検査項目の取りこぼしを見つけるために使います。
        

        

          
          
        

      

    

  


  

    
対応が必要なこと 

    

    

  


  

    
チェックリスト 

    

    

      「① コードで発火」から読みます。
      ここが「不発」の行は、右の項目を読む前に、その代理店コードの登録状況を確認してください
      (コードが効いていないので、右の項目はすべてその 1 つが原因です)。
      「不発の疑い」は差分はあるものの期待した変化が起きていないもので、実際にブラウザで開いて確認してください。
      「その他の異常」は、ほかの列に入らない異常 (console エラー・404・表示崩れなど) の件数です。
      内容はカード側に出ます。
      赤いセル = 期待と違う値。— = この代理店では検査していない。検査する代理店コードは実行ごとに抽選されます。
      「保存先」は正解が未確定のため表示のみ (赤にしません)。「Cookie+localStorage (両方)」は両方にあったという意味で、
      「Cookieのみ」はそこだけにあった、という意味です。他社タグ (計測・A/B テスト) の中に写っていたものは
      「他社タグに N 件」として別に数えます — これはサイトがコードを保持している証拠ではありません。

    ルール
    
        
    
          ここでの変更は config/overrides.yml に保存し、元の設定に重ねて使います。
          最新版に更新しても消えません
          (設定ファイルを直接書き換えると、更新のたびに消えるため)。
          変更は次の実行から効きます。理由は必ず書いてください
          (後から「なぜこの文言を登録したのか」を説明できるように)。
        
    
        
    
        
    
          
          
          
        
    
      
    

      
    
        
    そのほかの設定
    
        
    
          画面からは変えられません (安全装置・実行の重さに関わるため)。
          変えるには設定ファイルを直します。
